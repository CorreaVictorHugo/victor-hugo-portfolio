# 01 — Reference Analysis

## Referência

https://ewan-kerboas.fr/

## Propósito da referência

Estudar linguagem de interação e apresentação, sem realizar clonagem literal.

## Elementos a preservar conceitualmente

### 1. Experiência contínua

As mudanças de estado devem parecer parte de uma única experiência, evitando navegação seca entre páginas.

### 2. Projeto como protagonista

Cada projeto deve receber espaço visual significativo.

Evitar grids com muitos cards pequenos como elemento principal.

### 3. Tipografia editorial

Títulos grandes devem funcionar como parte da composição visual.

### 4. Movimento associado à navegação

Scroll, entrada de conteúdo e abertura de projetos devem conversar entre si.

### 5. Transição listagem → case

Este é um dos principais elementos desejados.

Ao selecionar um projeto, a transição deve preservar contexto visual sempre que possível.

Exemplo conceitual:

thumbnail/listagem
→ expansão/movimento
→ viewport
→ hero do case

Evitar simplesmente:

click
→ tela branca
→ nova página

### 6. Ritmo

Não animar tudo simultaneamente.

A experiência deve alternar:

- pausa;
- movimento;
- conteúdo;
- movimento;
- projeto.

## Mudanças obrigatórias em relação à referência

### Remover

- cursor personalizado;
- seção dedicada às tecnologias;
- estética dark como identidade principal.

### Alterar

- branding;
- cores;
- textos;
- projetos;
- composição específica;
- conteúdo comercial.

## Direção Victor

O site deve comunicar prestação de serviço de desenvolvimento web.

Projetos de clientes devem aparecer antes de informações técnicas sobre Victor.

## Regra de implementação

Quando houver conflito entre "ficar parecido com a referência" e "manter identidade própria", priorizar identidade própria.

A referência determina qualidade e linguagem de interação, não pixels.
