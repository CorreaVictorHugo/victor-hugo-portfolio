# 00 — Project Context

## 1. Projeto

Portfólio comercial de web design e desenvolvimento de Victor Hugo.

Este site NÃO é o portfólio profissional focado em Dados, Automação ou busca de emprego. Ele existe para apresentar trabalhos de desenvolvimento web realizados para clientes e apoiar prospecção de novos projetos.

## 2. Objetivo

Criar uma experiência visual moderna e premium que:

- apresente projetos reais;
- demonstre capacidade de design e desenvolvimento;
- gere confiança comercial;
- incentive contato;
- possa crescer conforme novos clientes/projetos forem adicionados.

## 3. Referência principal

Site:
https://ewan-kerboas.fr/

Usar como benchmark para:

- sensação de navegação contínua;
- transições entre páginas/projetos;
- ritmo das animações;
- composição editorial;
- uso de tipografia grande;
- apresentação imersiva dos projetos;
- interação ligada ao scroll;
- mudança entre listagem e case individual.

### Não copiar

Não reproduzir literalmente:

- código-fonte;
- textos;
- imagens;
- logotipo;
- identidade;
- composição pixel-perfect;
- assets;
- cursor customizado;
- seção de tecnologias;
- identidade dark original.

O produto final deve ser claramente um projeto independente.

## 4. Direção do novo produto

### Deve ser

- light mode;
- editorial;
- minimalista;
- sofisticado;
- altamente visual;
- orientado a projetos;
- responsivo;
- rápido;
- comercial.

### Não deve parecer

- currículo online;
- template genérico;
- dashboard;
- página de GitHub;
- catálogo de tecnologias;
- portfólio dark tradicional de desenvolvedor.

## 5. Público

Potenciais clientes procurando:

- landing pages;
- sites institucionais;
- redesign;
- páginas comerciais;
- aplicações web;
- soluções digitais sob medida.

## 6. Conteúdo ainda não definido

Não inventar dados.

Usar TODO claramente identificável para:

- nome comercial/estúdio;
- e-mail;
- WhatsApp;
- Instagram;
- domínio;
- lista final de projetos;
- descrições finais;
- depoimentos;
- métricas comerciais.

## 7. Princípio central

O trabalho realizado deve ser o protagonista.

Tecnologia é meio, não mensagem comercial.

A primeira impressão deve ser:

"Quero que meu site tenha esse nível de apresentação."

e não:

"Este desenvolvedor conhece muitas bibliotecas."
